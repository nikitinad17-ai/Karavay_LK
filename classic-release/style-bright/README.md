# Яркое оформление по старым версиям — 28.10.2026

Владелец сообщил, что текущая логика выглядит исправной, и прямо запретил её
менять. Визуальные референсы — два снимка старого кабинета: синий sidebar,
жёлтая активная навигация/CTA, синее приветствие и более выразительный шрифт.

Изменены только CSS и шрифты: насыщенная сине-жёлтая палитра, Ubuntu с кириллицей,
карточки/формы/таблица/диалоги и адаптация для узкого экрана. Панель заказа на
средней ширине переносится ниже каталога, чтобы наименование не сжималось в
узкую колонку. Состав разделов, поля и действия сохранены. Новых статистических
данных, статусов или фиктивных контактов из референса не добавлено.

Исходники: `src/classic/base.css` сохраняет прежние дополнительные стили,
`bright.css` содержит новое оформление; `styles.css` последовательно подключает
обе таблицы. `App.tsx`, `api.ts`, `repeatOrder.ts`, `main.tsx` и все hooks
побайтно совпали с контрольной точкой до этого задания (9 файлов).

## Установка

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "$env:USERPROFILE\Downloads\Karavay-Style-Bright-20261028.ps1"
```

Установщик **не подменяет приложение новым бандлом**. Он добавляет одну таблицу
стилей непосредственно в установленный HTML. После удаления только этого блока
получаются точно прежние байты страницы; все script tags и их содержимое
сравниваются до записи. Повтор заменяет только собственный блок оформления.
Шрифты включены в CSS; обращения к внешним шрифтовым серверам не нужны.

Проверяются известный SHA исходной страницы, фактический HTML сервера, неизменные
IDs демо и hashes helper/config/миграций/менеджера. Есть закрытая резервная копия
HTML и возврат прежнего файла при ошибке или Ctrl-C. БД, users/rights, КИС и
менеджер не изменяются; нет миграций, POST или перезапуска PocketBase.
Успех: `BRIGHT_STYLE_READY`, затем Ctrl+F5. На реальной VM применение ещё не
подтверждено. Нативного запуска PS1 в текущей среде нет.

## Ubuntu

Сохранены семейство/метаданные Copyright 2011 Canonical Ltd. и Ubuntu Font Licence
1.0. Полный текст лицензии включён в CSS-комментарий и
`src/classic/fonts/Ubuntu-LICENCE.txt`. Источник лицензии:
https://github.com/google/fonts/blob/main/ufl/ubuntu/UFL.txt

Сборка установщика:
`python3 classic-release/style-bright/build-package.py /path/to/output`.
Браузерная проверка:
`node classic-release/style-bright/visual-check.cjs /path/to/patched.html /path/to/screenshots`.
Для дополнительного Chromium можно задать BROWSER_CONFIG с executablePath/args;
это параметры тестовой среды, не часть установленного приложения.
