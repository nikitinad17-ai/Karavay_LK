## Исходная история Git

Архив ZIP содержал три коммита старой версии и незакоммиченные изменения v3.2.
GitHub получает актуальный снимок проекта; предшествующая история сохранена
отдельным Git bundle, а не включена в цепочку новых коммитов GitHub.
Чтобы посмотреть исходную историю из корня скачанного репозитория:

```sh
git clone docs-project/archive/source-history.bundle ../Karavay-LK-original-history
```

Этот клон содержит старые коммиты. Для работы с v3.2 используйте текущий репозиторий.
