# AGENTS.md

Перед работой прочитать `PROJECT_CONTEXT.md` и `readmegpt.md`.

- Основная реализация находится в `src/`; редактировать исходники, не `dist/`.
- Сохранять модель покупатель → торговые точки и все шесть разделов кабинета.
- Правила количества держать едиными для каталога, проверки, корректировки и API.
- Не мутировать заказы и массивы позиций напрямую.
- Для запросов, зависящих от выбора пользователя, отсекать устаревшие ответы.
- Не подключать реальную авторизацию или production API без явного задания.
- После изменений запускать `npm run check`; при доступном Chromium — `npm run test:e2e`.
- Обновлять документацию вместе с изменениями поведения.
- Не коммитить секреты, `node_modules/` и `dist/`.
