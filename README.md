# КАРАВАЙ · Личный кабинет

Демонстрационный личный кабинет клиентов КАРАВАЯ, **v3.2**.
Репозиторий: [nikitinad17-ai/Karavay_LK](https://github.com/nikitinad17-ai/Karavay_LK).

Здесь собраны исходники, готовый HTML и история решений проекта «Личный кабинет».
Приоритет — удобство интерфейса и проверка поведения прокрутки, меню и окон.

## С чего начать

1. [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md) — актуальные решения, ограничения и дальнейшие шаги.
2. [readmegpt.md](readmegpt.md) — журнал изменений, выполненные проверки и ограничения.
3. [CONTRIBUTING.md](CONTRIBUTING.md) — работа с исходниками и сборка.
4. [Документы проекта](docs-project/README.md) — конспекты и архивные материалы.

## Запуск

Скачайте репозиторий через **Code → Download ZIP**, распакуйте и откройте
`index.html` в браузере. Для разработки используйте `app/index.html`.

Демонстрационный вход покупателя: `B-1024` / `master1024`.
Данные и пароли в `app/api.js` предназначены только для демо.
Реальная авторизация, серверная проверка прав, PocketBase и VM пока не внедрены.

## Что есть в v3.2

- Обзор, оформление и история заказов, документы, профиль и торговые точки.
- Проверка состава, количества, суммы, получателя и даты перед отправкой заказа.
- Закреплённая панель с итогом и проверкой заказа на телефоне.
- Исправления случайного закрытия окон, потери прокрутки и фокуса.
- Раздельное оформление хлебобулочной и замороженной продукции в демо.

Иерархия бизнеса: **Покупатель → Получатели / торговые точки**, около 600 точек.
Существующий демонстрационный API не подтверждает контракт реальной КИС.

## Сборка и проверки

Нужны Python 3 и Node.js. Из корня репозитория:

```sh
node tests/ui-regression.js
python3 build_inline.py
```

Затем скопируйте сборку в корень:

```powershell
# Windows PowerShell
Copy-Item app/standalone.html index.html
```

```sh
# Linux / macOS / Git Bash
cp app/standalone.html index.html
```

44 изолированные проверки логики не требуют установки зависимостей.
Для отдельных браузерных сценариев после сборки:

```sh
npm install
npx playwright install chromium
node tests/t2.js
```

При переносе 10 сентября 2026 года повторно пройдены 44 проверки логики,
проверен синтаксис JS и подтверждено побайтовое совпадение сборки с присланным HTML.
Браузерные сценарии в этом переносе не запускались; проверка реальной прокрутки
и экранной клавиатуры телефона остаётся следующей задачей.

Новые изменения начинаются с исходников; `index.html` обновляется сборкой.
После изменения поведения обновляйте `readmegpt.md`, после смены решений —
`PROJECT_CONTEXT.md`. Старые утверждения об авторизации и КИС хранятся как
история обсуждения и не считаются подтверждённой реализацией.
