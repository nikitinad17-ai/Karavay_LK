# Формат создания заказа КИС — 28.10.2026

Владелец проекта передал пример JSON и уточнил, что его прислали разработчики
КИС. Это источник нового формата запроса; успешный ответ API пока не предоставлен.
Идентификаторы в примере ниже тестовые.

```json
{
  "client_id": 300183,
  "order_date": "2026-10-30T00:00:00",
  "products": [
    {"id": 425162, "kol_sht": 3},
    {"id": 425163, "kol_sht": 6}
  ]
}
```

Меняется только исходящий JSON `POST /api/v1/orders` в `karavay-checkout.js`.
Браузерный `/service/orders`, выбор получателя и датированная матрица остаются
совместимыми: шлюз преобразует `client` в `client_id`, `DateOrd` в локальную дату
с `T00:00:00`, позиции `id/quantity` в `id/kol_sht`. Цены, `payer`, `Group` и
токен PocketBase в КИС не передаются. Количество — штуки, уже рассчитанные из
лотков и отдельных штук. Старый формат POST не пробуется повторно.

Сохраняются проверки пользователя, роли, прав, активности и принадлежности
получателя, матрицы, цены и допустимого количества. Серверный журнал запросов
не очищается: успешные и неопределённые прошлые отправки не повторяются.

Формат ответа не выдумывается: пока остаются проверенные ранее варианты
`success: true`, `data.id` или `data.Id_ord`. После получения ID шлюз читает
карточку заказа и сверяет получателя, дату, позиции и количества. Неизвестный
или неоднозначный результат остаётся `SUBMISSION_UNKNOWN`, без повторного POST.

Установка этого изменения не создаёт заказ. Её признак `KIS_ORDER_FORMAT_INSTALLED`
подтверждает установленные файлы и работу службы, а не создание заказа в КИС.
Для подтверждения реальной интеграции нужен результат одного обычного заказа,
отправленного пользователем, и соответствующая карточка в истории.

Проверки: отдельные тесты формы JSON, границ года, високосной даты и календарного
дня UTC+3; интеграционный сценарий PocketBase с локальным имитатором КИС проверяет
точный JSON, права, количество, цены, журнал, тайм-ауты и отсутствие повторов.
Рабочая VM и реальные заказы в этих проверках не используются.

Фактически прошли: `npm run check` (52 теста), отдельная сборка Classic и CSP,
6 тестов тела запроса и интеграционный сценарий настоящего PocketBase 0.40.3
с локальным имитатором КИС. Для отдельного установщика прошли 8 проверок:
сохранность файлов/БД, точечная замена, резервная копия, повторный запуск,
неизвестные версии, ожидающие миграции, повреждение пакета и откат при сбое.
Корневой React E2E в этом запуске не прошёл: Chromium отсутствует в ожидаемом
пути Playwright. Это не заявляется успешной браузерной проверкой; интерфейс
в данном изменении не редактировался.

Исторический отказ со старым форматом сохранён в
[отчёте 17.10.2026](KIS_ORDER_CREATE_FAILURE_2026-10-17.md).
