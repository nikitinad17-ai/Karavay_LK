# Журнал изменений

## 2026-10-28 — яркое оформление Classic без изменения логики

- Возвращены насыщенная сине-жёлтая палитра, выразительные карточки и шрифт
  Ubuntu с кириллицей; доработано отображение каталога на средней ширине и телефоне.
- Отдельный установщик меняет только CSS установленной страницы, сохраняет JS,
  пользователей и права; предусмотрены резервная копия и откат.
- Манифесты демо-пакетов согласованы с текущей сборкой; сохранена совместимость
  с ранее выданным HTML 3.8.5. Установщик стилей принимает обе сборки.
- Подробности и ограничения: [последние изменения](docs/LATEST_CHANGES_2026-10-28.md).
- Локально пройдены 52 unit/DOM-теста, сборки, проверки установщиков и браузерный
  сценарий Classic. Старый E2E-набор React 3.5: 1 PASS / 7 FAIL. Применение на VM
  не подтверждено.

## Classic 3.8.5 — 2026-10-27

- Убран служебный «Статус КИС», вся строка истории открывает карточку заказа.
- Повтор доступен из строки и карточки: актуальные дата/группа/прайс, сохранение
  общего количества штук, явное подтверждение частичного переноса и замены корзины.
- Добавлены три passwordless демо-сценария; второй обязательно проверяет минимум
  двух активных получателей. Подбор не блокируется пустой историей или отказом прайса.
- История и цены не генерируются. Создание заказа с ошибкой aId_Clt остаётся на паузе.

## 2026-10-08 — передача контекста и решение по шлюзу КИС

- Сохранены отсутствовавшие в основных документах решения из предыдущего чата.
- Зафиксирована актуальная модель `users/roles/rights/payers/clients`, email-auth,
  общий доступ к получателям и расхождение с ранними React-ветками.
- Добавлены схемы сохранения PocketBase на VM, внешнего HTTPS и внутреннего КИС.
- Приняты публичные `/service/*` и роль шлюза внутри PocketBase через `pb_hooks`.
- Отменено прежнее предположение об обязательном сервисном токене КИС.
- Добавлены карта маршрутов, проверки доступа, ошибки и критерии первого каталога.
- Сохранена контрольная точка для следующего чата с точными ссылками на ветки
  и standalone 3.6.3; старые инструкции и OpenAPI помечены как исторические.
- Обновление касается документации; версия runtime и статус подключения КИС
  от этого не меняются.

## 3.5.0 — 2026-09-15

- Добавлен режим `PocketBase directory` без фиксированных demo-кодов.
- Покупатель загружает только связанные активные записи `outlets`; поддерживается пагинация для ~600 точек.
- Получатель видит только собственную точку и связанного покупателя.
- Полная auth-запись не сохраняется: в `sessionStorage` остаётся минимальная сессия.
- Заказы, матрица и документы заблокированы до подключения серверного API КИС.
- Добавлены строгая проверка обязательных полей, обработка 403/404 и unit-тесты directory API.
- Добавлена сборка одного HTML для `/opt/pocketbase/pb_public/index.html`.
- Зафиксированы поля, API rules и безопасные тестовые записи в `docs/POCKETBASE_DIRECTORY_SETUP.md`.

## 3.4.0 — 2026-09-15

- Приложение, компоненты, store, API-адаптеры, mock и тесты перенесены на TypeScript.
- Добавлен единый набор доменных и API-контрактов в `src/types.ts`.
- Включён строгий `tsconfig`; проверка типов стала обязательной частью `npm run check`.
- Обновлены Vitest и Playwright-сценарии для проверки TypeScript-кода.
- Сохранены интерфейс, шесть разделов и бизнес-поведение React 3.3.
- Сохранён PocketBase-контур этапа 2.1 без создания тестовых пользователей.
- Добавлена явная блокировка учётных записей с `must_change_password=true`.
- Обновлены Vite 8, Vitest 5 и jsdom 30; `npm audit` проходит без уязвимостей.
- Добавлена воспроизводимая сборка одного автономного HTML со встроенными ресурсами и демонстрационным PDF.

## Этап 2.1 — в работе

- Разделены режимы авторизации и бизнес-данных.
- Mock API вынесен за явный build-флаг и исключён из production-сборки.
- Добавлена авторизация через PocketBase `buyers` и `outlets` по `kis_code`.
- Добавлены обновление и восстановление сессии, а также очистка токена при выходе и ошибках связывания.
- Сессия минимизирована; пароль и полная auth-запись не сохраняются.
- Для auth-запросов добавлены таймаут и `X-Request-ID`.
- Зафиксированы OpenAPI, JSON Schema ошибки и таблица auth-ошибок.
- Добавлены тесты auth-адаптера и сборка `dist-pocketbase/` для проверки на VM.
