# Менеджер 0.9.2 — разные назначения для покупателя и получателя

Дата: 28.10.2026. База: менеджер 0.9.1, GitHub-коммит `2f1e4ef`.

## Два исправления

1. **Разные списки назначений.** Для «Покупателя (Payer)» показаны компании:
   галочка даёт доступ ко всем действующим точкам выбранного покупателя.
   Для «Получателя (Client)» покупатель выбирается отдельно, а основной список
   содержит именно торговые точки: код, название и адрес. Есть поиск точки.
   Выбранные точки сохраняются при переходах между покупателями; счётчик и
   кнопки с кодами покупателей позволяют вернуться к уже выбранным назначениям.
   Переключение роли само по себе не выбирает все точки. Черновики выбора компаний
   и точек сохраняются при переключении роли в открытой форме.
2. **Роли в форме.** Убраны недоступные пункты «Администратор» и «Менеджер».
   Администратор PocketBase управляет базой и настройками; менеджер управляет
   клиентскими пользователями в своей области доступа. Их учётные записи нужны,
   но эта форма предназначена для Client/Payer. Существующий «Только просмотр»
   остаётся доступен при редактировании соответствующей старой записи.

Четыре поля создания пользователя, таблица, оформление, демо, пароли и тестовые
входы сохранены. Назначения по-прежнему выбираются через «Изменить».
Служебные числовые ID убраны из строк выбора покупателей; у точек остаются
код, название и адрес.

## Данные и доступ

Новых миграций и изменений схемы относительно 0.9.1 нет. Сохраняется модель
`users → rights → payers → clients`, включая существующее поле `account_type`.
Клиентский кабинет, обработчики заказов и конфигурация КИС не заменяются.
Неактивные/чужие компании недоступны для назначения. Менеджер с правами только
на отдельные точки не может через выбор Payer выдать доступ ко всей компании.
Серверная проверка прав сохраняется.

Смена покупателя в выборе точек не выдаёт доступ: сохраняются только отмеченные
точки. Запоздалые ответы после смены роли или закрытия формы не применяются.
Просмотр списка другой компании сам по себе не считается изменением назначений.

## Установка

Скачать `Karavay-Manager-0.9.2-Assignments-20261028.ps1` в «Загрузки»:

```powershell
cd ([environment]::getfolderpath('userprofile') + '\downloads')
powershell -noprofile -executionpolicy bypass -file .\karavay-manager-0.9.2-assignments-20261028.ps1
```

Успех: `MANAGER_RELEASE_INSTALLED: 0.9.2`, затем `TEST LOGIN READY`.
Открыть `/manager/` и нажать Ctrl+F5. Обычный запуск не создаёт и не перенастраивает
демо. Для этого обновления `-ResumeSetup` не нужен.

Установка на внутреннюю VM из среды разработки не выполняется; её результат
подтверждает оператор. Проверки с локальными ответами КИС не подтверждают
действующую интеграцию КИС на сервере.
